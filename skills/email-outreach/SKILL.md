# Email Outreach

## A reply-worthy cold email
- **Subject**: 3–5 words, specific, no clickbait. ("Question about <their thing>").
- **Opener**: one line proving you researched them (not "I hope this finds you well").
- **Value**: one concrete, relevant benefit. One idea per email.
- **Ask**: a single low-friction CTA ("Worth a 15-min call Thursday?").
- **Length**: under 120 words. Plain text. One link max.

## Sequence (4 touches over ~2 weeks)
1. Day 0 — initial value email.
2. Day 3 — short bump + new angle.
3. Day 7 — case study / proof.
4. Day 12 — polite breakup ("should I close the loop?").

## Compliance (CAN-SPAM / GDPR)
- Use a real from-name and physical address. Include a working unsubscribe/opt-out.
- Honor opt-outs immediately. Don't use deceptive subjects. B2B only unless consented.

## Tooling
- Personalize with the lead's data. If a CRM/email MCP is connected, draft there; otherwise output ready-to-paste copy. Never auto-send without the user's confirmation.
