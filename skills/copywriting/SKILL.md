# Copywriting

## Principles
- Lead with the **outcome/benefit**, not the feature. "Ship faster", not "has a fast compiler".
- One core message per page. Clear > clever. Concrete > vague (numbers, specifics).
- Write to one reader ("you"). Match their awareness stage (problem → solution → product).

## Landing page skeleton
1. **Hero**: outcome headline + one-line subhead + single primary CTA.
2. **Social proof**: logos, numbers, a real quote.
3. **Problem → solution**: name the pain, show the fix.
4. **Features as benefits**: 3–6, each "so that you can…".
5. **Objection handling / FAQ.** 6. **Final CTA** (repeat the primary action).

## Headlines
- Try 5–10 variants. Patterns: how-to, outcome, question, "stop X / start Y", number-led.

## Voice
- Active voice, short sentences, no jargon or hype words ("revolutionary", "synergy"). Read it aloud.

## Don't
- Don't make claims you can't back. Don't bury the CTA. Don't write a wall of text.
